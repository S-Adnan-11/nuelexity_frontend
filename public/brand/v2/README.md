# Nuelexity Return Cat

Use the sage variants on dark surfaces and the ink variants on light surfaces. Use the small marks at 16–32 CSS pixels. Keep the original aspect ratio, clear space and colors.

The outlined wordmarks need no font download. Manrope and DM Serif Display are served locally under the SIL Open Font License 1.1. Keep their license notices alongside the font files.

The social image is `social/open-graph.png`. Favicons, install icons and the web manifest are in `icons/`.
