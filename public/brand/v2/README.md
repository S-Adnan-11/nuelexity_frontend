# Nuelexity Return Cat v2

Approved production assets supplied by the owner on 2026-10-15, following approval of the Return Cat direction on 2026-10-14. The SVG geometry and outlined wordmarks are copied from the editable production masters in the workspace's `nuelexity-brand-v2` kit. Runtime components use these SVGs, not exploration screenshots.

Use sage variants on the current dark app theme and ink variants on explicit light surfaces. Small masters are for 16–32 CSS pixels; larger marks include the blue eye. Preserve aspect ratio, clear space, and the supplied colours. Do not add gradients, crop, stretch or rotate the logo.

Manrope and DM Serif Display are redistributed under SIL Open Font License 1.1. Keep `fonts/Manrope-OFL.txt` and `fonts/DMSerifDisplay-OFL.txt` with the WOFF files. Wordmarks are outlines and require no font downloads. Bun bundles the self-hosted WOFF files into local CSS; there is no font CDN dependency.

The social image belongs at `https://nuelexity.devs.surf/brand/v2/social/open-graph.png` after the owner configures hosting. See `docs/RETURN_CAT_IMPLEMENTATION.md` in the frontend repository for placement inventory, verification and external setup.
